## Mathematical correspondence

An exact binary excess coverage array at $(N,t,k)=((t+1)!,t,k)$ is a binary balanced array with index by weight $\mu_a=a!(t-a)!$. Traditional balanced-array papers often write the constraints as rows and the repeated runs as columns. Transposing that convention gives the array orientation here. Column-permutation symmetry here means a constant multiplicity on each weight orbit, the simple-array model.

In the SCA reduction use a distinguished element $e$, with a bit indicating whether each other event precedes $e$. The arrays use $t=s-1$, $k=v-1$, and $N=s!$. A specified pattern with $a$ predecessors of $e$ and $t-a$ successors corresponds to the $a!(t-a)!$ orders of these $s$ events. Each order appears exactly once at the perfect SCA row count. Thus $v=2s-1$ gives $k=2t$. This only applies in the forward direction. Relations among multiple projected arrays can add information beyond the existence of one binary array.

A directed Steiner system of this form orders every four-element subset in all 24 ways once, giving the counterexample $\operatorname{SCA}(24;4,6)$ discussed in the Gentle–Horsley–Wanless introduction.
